---
description: 断开 aop 协作网络——停止后台 aop-collab 代理，回到独驾
---

用户要求断开 aop。执行：

## 通知后台代理退出

对运行中的 aop-collab 后台代理发 SendMessage（to 填它的 agent id；若不知道 id，直接告知用户「后台代理会在下一轮查询时自动退出」即可）：

```
[aop-stop] 用户断开协作网络，请结束循环退出。
```

（备用通道：aop 工作区的「断开」钮写 stop 标志——代理下一轮 aop_myco 自动读到退出，双通道等效。）

## 向用户确认

```
🔗 已断开 aop 协作网络。
后台代理已停止（至多再轮询一轮）。回到独驾。
需要时说「连接 aop」随时重连。
```

回到正常对话模式。不需要删除 MCP 插件（下次 /aop-connect 可直接重连）。
